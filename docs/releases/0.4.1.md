# BeamFix 0.4.1 — GPLv3 distribution (experimental)

BeamFix is now released under **GPL-3.0-only**. This release retains the offline
browser GUI, independent CLI and portable Linux installer introduced in 0.4.0.
Use this release for packages containing the full license and copyright notices.

- Includes LICENSE and NOTICE in wheel, source and portable packages and keeps
  them in the user installation.
- Adds offline license and copyright links to the GUI.
- Documents GPL commercial distribution and the contribution policy for any
  future separately licensed commercial edition.
- Verifies packaged license texts and SPDX metadata during release checks.

Download `beamfix-0.4.1-linux-portable.tar.gz`, extract it and run
`python3 launch.py gui`, or `python3 install.py` for a user application-menu entry.
Python 3.11+ and a browser are required. CLI use remains available.

This is still experimental. Automated tests and simulated recovery checks do
not replace validation on the actual Fedora GNOME laptop and classroom projector.
Optional external `drm_info` is not installed by the package: check it in the
same terminal environment before the classroom trial.
