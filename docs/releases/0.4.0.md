# BeamFix 0.4.0 — offline GUI and portable Linux package

BeamFix now provides a local browser interface alongside its independent CLI.
This experimental release is intended for private testing. Real Fedora Workstation
GNOME and classroom/projector acceptance remains open.

## What's included

- Four illustrated starting situations: No signal, black projection, desktop
  without the presentation, and room monitors working without projector output.
- Shared diagnostic readings and guided checks, explicit output identification,
  user-reported classroom connection context and downloadable JSON summaries.
- Previewed KDE/GNOME Wayland activation and bounded mode trials using the existing
  independent timeout/recovery worker. Only an explicit projector confirmation
  keeps a verified change; Stop or lost browser interaction requests undo.
- An offline portable archive, user installer with a menu entry, standard Python
  wheel and source package. No new Python runtime dependencies.
- Changes since the previous GitHub version (0.3.2): GNOME mode trials, classroom
  AV workflows and read-only signal properties/detailed timings through `drm_info`.

## Choose a download

- **`beamfix-0.4.0-linux-portable.tar.gz`**: extract and run without pip or installation.
- **`beamfix-0.4.0-py3-none-any.whl`**: install into an existing Python environment.
- **`beamfix-0.4.0.tar.gz`**: source distribution with tests, docs and build scripts.
- **`beamfix-0.4.0-SHA256SUMS`**: integrity checksums for those three files.

Use the named portable asset, rather than GitHub's automatically generated source
archives, for the ready-to-run layout and installer.

## Portable quick start

Requires Linux, Python 3.11 or later, and a modern browser for the GUI:

```bash
tar -xzf beamfix-0.4.0-linux-portable.tar.gz
cd beamfix-0.4.0
python3 launch.py gui
```

The CLI remains available:

```bash
python3 launch.py doctor
python3 launch.py troubleshoot --try-fix
```

Optionally install for your user, including the **BeamFix** menu entry:

```bash
python3 install.py
```

No sudo, pip or Internet connection is needed for portable operation or the user
installer. Python and optional desktop helpers are not bundled. Install the
optional distribution package **`drm_info`** to collect advanced signal details,
including on the Fedora classroom computer; missing it leaves those details
explicitly unavailable while basic diagnostics continue. Automatic GNOME changes
also require `busctl` with JSON support and Mutter DisplayConfig; KDE uses
`kscreen-doctor`. Other desktops keep available diagnostics and manual guidance.

## Validation and limits

265 local tests passed, including isolated GNOME D-Bus transport and real helper
processes operating on simulated displays. Browser layout and the guided classroom
flow were checked, including an 800×600 window. Installed CLI diagnostics were
checked read-only on the development KDE session. Offline install, update, removal,
menu-file validation and unrelated-file protection were verified in a temporary
prefix. The release workflow also tests Python 3.11 and 3.14 before publishing.

These checks do not certify compatibility with a physical projector. Before
classroom use, complete `docs/automatic-activation-checklist.md` on the Fedora
Workstation GNOME computer and actual AV system, including timeout and recovery.
An image on room monitors alone is never projector confirmation.
